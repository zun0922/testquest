# テストデータ管理の原則

- テストデータは本番データと **分離して管理** する（専用ディレクトリ・専用ファイル）
- テスト完了後は **必ず本番データ・本番設定に復元** する
- 復元した事実はテストログの `notes` 欄に「TD-XXX使用・復元完了」のように記録する
- 本番データへのテストデータ混入が疑われる場合は **即座に人間へ報告** する
- コード改変型のテストデータ（初期値変更・パス差し替え等）は、変更箇所と復元方法をテストデータ表に明記する
- URL パラメータでテストデータを切り替える場合は **dev モード限定** とし、本番ビルドでは無効化する
