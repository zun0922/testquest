## 1. なぜ改版したか

Phase 2 の5機能（ボイス・ヒント・エンディング・既読スキップ／バックログ・編成パターン）は
**2026-08-25〜09-13 にすべて本番稼働**した。しかしテスト系文書は Phase 1 のままで、次の乖離が生じていた。

| 乖離 | 実態 |
|------|------|
| **受け入れ基準が Phase 1 分（AC-001〜012）しかない** | 本番稼働中の5機能に「何をもって合格とするか」の定義が無い |
| テスト計画書が Phase 2 を「**未実装フェーズの機能**」として対象外と明記 | 5機能とも本番稼働済み。記述が実態と正反対 |
| テスト仕様書が「Phase 2〜4。**本書では扱わない**」と明記 | 同上 |

品質そのものの問題ではない（**E2E 28件＋単体280件で毎回検証している**）。
**文書だけが実態に追いついていない**状態が約3週間続いていた。

> **教訓（テスト計画書 §2.2 に注記として記録）**
> 機能を本番へ出すときは、**テスト文書の対象範囲も同じタイミングで動かす**。
> 要件定義書に FR を足すだけでは、テスト系文書は「対象外」のまま取り残される。

## 3. 人手で実施していただくテストは「7件だけ」増えます

自動と同じことを人手で繰り返すのは、手動テストの枠を圧迫するだけで品質に寄与しない。
そこで**機械に判定させられない観点だけ**を手動に残した。

| TC-ID | 何を見るか | なぜ人間か |
|-------|-----------|-----------|
| ST-M2-001-TC-001 | **実機での音声再生**（iPhone・横持ち） | ヘッドレスでは音が鳴らない |
| ST-M2-001-TC-002 | 音声とテキスト送りの並行 | 同上 |
| ST-M2-002-TC-001 | 読み上げの品質（専門用語） | 「正しく聞こえるか」は聴感 |
| ST-M2-002-TC-002 | **声と口調の相性**（澪の編成） | 本文は匠と共通のため、女性音源で不自然でないかは主観判断 |
| ST-M2-003-TC-001 | **ヒント文の粒度** | 答えを言っていないか／役に立つかは内容の判断 |
| ST-M2-004-TC-001 | **エンディング本文の読み味** | 未取得の実務能力を断定していないか |
| ST-M2-005-TC-001 | スキップの体感速度 | 「目で追えるか」は体感 |

いずれも**直し方が軽い**という共通点がある（読み間違い＝辞書登録して該当分のみ再生成／
ヒント・エンディング本文・編成の口調＝データ修正のみでコード変更不要）。
そのため**指摘が出ても手戻りは小さい**。
