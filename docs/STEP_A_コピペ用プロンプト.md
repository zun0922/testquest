# STEP A：AI Studio ブラウザ生成用・コピペプロンプト

**正となる文書**：`画像生成プロンプト集_v0.1.md`（v1.0承認済み）。本ファイルはその§1＋§2を**貼るだけの形に連結した作業用コピー**（対訳はプロンプト集を参照）。

## 手順（1キャラあたり1〜2分）

1. https://aistudio.google.com/ を開く（yuya0922zun3523@gmail.com でログイン済みのブラウザ）
2. モデルで **画像生成モデル（Nano Banana / Gemini Flash Image 系）** を選択
3. 下のプロンプトを貼って実行。**同じプロンプトでもう1回**実行（=各キャラ2案）
4. 生成画像を右クリック等で保存：
   - 保存先：`testsim\assets-candidates\stepA\`（フォルダは私が作成済み）
   - ファイル名：`rin_normal_a.png` / `rin_normal_b.png` / `tanaka_normal_a.png` … の形式
5. 6枚たまったら私に「保存した」と伝えてください → 設定書適合チェックに進みます

> 縦横比を指定できるUIがある場合は **3:4（縦長）** を選択。なければそのままでOK（後工程で調整可能）。
