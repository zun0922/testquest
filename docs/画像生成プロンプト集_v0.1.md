# TestQuest 画像生成プロンプト集 v1.4

| 項目 | 内容 |
|------|------|
| 元ドキュメント | `画像デザイン設定書_v0.1.md`（設定の正はそちら。本書は投入用への変換） |
| 想定サービス | Google AI Studio（Gemini 画像生成・編集）第一候補 |
| 作成日 | 2026-07-02 |
| 状態 | ✅ 承認済み（2026-07-02 PO承認・設定書と同時） |

使い方：
1. **STEP A（基準画像）**：§2 の各キャラ「基準プロンプト」で normal を数案生成
2. **STEP C（表情差分）**：採用画像を添付した上で §3 の「編集指示」を使う（テキストのみの再生成は禁止）
3. §1 の共通スタイル文はコピーして各プロンプトの末尾に付ける

> **プロンプトが英語である理由**：画像生成AIは英語キャプションで学習されており、英語指示の方が出力品質が安定するため（特に Stable Diffusion 系は事実上英語専用。代替サービスへの可搬性も考慮）。
> **AIに投入するのは英語（コードブロック内）のみ**。直後の「対訳」はレビュー用であり、投入しない。

## 3. 表情差分の生成方法 ※v1.2：Gemini画像編集方式に変更（採用済み方式）

seed固定＋語句差し替え方式（v1.1）は、目の左右非対称・表情間の目のスケール不一致がPOレビューで不合格となったため廃止。**採用画像を入力に、Gemini API（`gemini-3.1-flash-image`・課金必須）で表情のみを編集**する。

手順：
1. 採用済み基準画像（PNG）を `inline_data` としてリクエストに添付
2. 下記の「共通ガード文＋表情指示」をテキストとして添付
3. `generationConfig.responseModalities = ["IMAGE"]` で画像出力を指定
4. 生成後、基準画像と並べて同一人物か・目の対称性を確認（STEP D）

共通ガード文（毎回付ける）：

```
Keep this exact same character and illustration: same face shape, same
hairstyle, same hair color, same clothes, same colors, same art style,
same pose, same framing, same background. Keep the same eye size and
keep both eyes perfectly symmetrical with matching pupils and matching
highlights in both eyes. Change ONLY the facial expression to:
```

**対訳**：この同じキャラクターとイラストを厳密に維持すること：同じ顔の形・髪型・髪色・服・配色・画風・ポーズ・構図・背景。**目の大きさを維持し、両目は瞳孔とハイライトが一致した完全な左右対称を保つこと**。表情だけを以下に変更する：

| 表情 | 続けて記述する指示（英語） | 対訳 |
|------|-------------|------|
| happy | `a bright happy smile, eyes slightly closed with joy, cheerful.` | 明るく嬉しそうな笑顔、喜びで少し細めた目、陽気に |
| angry | `furrowed brows, a displeased frowning expression, tense mouth.` | 眉間にしわ、不機嫌にしかめた表情、引き締めた口元 |
| sad | `sad downcast eyes, slightly lowered eyebrows, a worried unhappy mouth.` | 悲しく伏せた目、少し下がった眉、心配そうで沈んだ口元 |
| thinking | `a thoughtful expression, eyes looking up and away, pondering.` | 考え込む表情、視線は上の方へ外す、思案中 |
