## 1. 実施手順

```
cd testsim
npm run dev
→ ブラウザで http://localhost:5173/?skipTyping=1&unlockAll=1
```

- `?skipTyping=1`：文字送りアニメーションを省略（確認効率化）。**読み味のテンポ確認をしたい回だけ外す**
- `?unlockAll=1`：FL未クリアでも AL を解放（**devモード限定・本番ビルドでは無効**）
- 進捗は localStorage（`testquest:save`）。リセットはタイトル「はじめから」→上書き確認OK
- 中断・再開自由（「つづきから」）。メモは本シートの表に直接どうぞ

| # | 観点 | 見るポイント |
